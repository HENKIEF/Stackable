# Stackable
*B2B software for 3D-nesting and material optimization in the tool and mold making industry.*

We are building 'Stackable' to streamline resource-intensive manufacturing workflows. We plan to use the Claude API to process complex, unstructured manufacturing requirements and translate them into parameters for our Python-based geometric algorithms. The expanded rate limits and API credits will allow us to scale our processing backend.

### Current Status & Traction
* **Software:** Core Python-based 3D nesting algorithms and geometric modeling integration (via FreeCAD) are operational.
* **Validation:** We are currently testing and validating our algorithms with real production data in collaboration with our industry partner, **Germa Composites GmbH**.
* **Team:** Developed by a team of mechanical engineering researchers and Master's students (Leon Elbers, Henning Kiefer, and myself), specializing in product development at RWTH Aachen University.
